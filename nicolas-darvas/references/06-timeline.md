# 06-timeline.md — Nicolas Darvas's Life and Career Timeline

---

| Year | Event |
|------|-------|
| 1920 | Born in Hungary |
| 1943 | Fled Hungary with forged exit visa and 50 pounds sterling |
| 1943-1950s | Built dancing career with half-sister Julia; performed worldwide |
| 1953 | Appeared with Judy Garland and Bob Hope |
| ~1952-1957 | Read ~200 books on markets; started studying speculation |
| 1956 | First stock trades; developed box theory |
| 1957-1959 | $36,000 → $2,000,000 using box theory |
| 1959 | Time Magazine profile (May 25) |
| 1960 | Published How I Made $2,000,000 in the Stock Market |
| 1960 | NY Attorney General investigation (dismissed by court) |
| 1964 | Published Wall Street: The Other Las Vegas |
| 1965 | Published The Anatomy of Success |
| 1971 | Published The Darvas System for Over-The-Counter Profits |
| 1977 | Published You Can Still Make It in the Market |
| 1977 | Died in Paris, France |
